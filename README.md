# NeuroGuardian AI

### Multimodal AI-Based Headache and Eye-Health Screening & Monitoring Platform

## Overview

NeuroGuardian AI is a final-year B.Tech Computer Science and Engineering project designed to provide preliminary headache and eye-health screening information through a web-based platform.

The application brings together screening and health-information features through a common interface. It aims to help users review reported symptoms, understand available screening results, and identify when professional medical consultation may be appropriate.

## Key Features

- User registration and login
- AI Health Assistant
- Eye and Neurological Screening
- Brain Disease Risk Screening
- Migraine Analysis
- Vision Screening
- Blood Report Analysis
- CT and MRI Report Analysis
- Report History
- Multilingual support for supported features
- Voice-based interaction where implemented

*Feature availability depends on the current implementation of the application.*

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python and Flask
- **Database:** SQLite
- **Development Environment:** Visual Studio Code
- **Additional Libraries and APIs:** As required by the implemented modules

## Installation and Setup

1. Install Python and Git.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Install the dependencies listed in `requirements.txt`, if provided:

   ```bash
   pip install -r requirements.txt
   ```

5. Configure the database and any required environment variables according to the project setup.
6. Start the Flask application using the appropriate command. If the entry point is `app.py`, run:

   ```bash
   python app.py
   ```

7. Open the local URL displayed in the terminal. For the default Flask development address, this is commonly `http://127.0.0.1:5000`.

## Disclaimer

NeuroGuardian AI is an educational project that provides preliminary screening information. It is not a medical diagnostic system and does not replace consultation, diagnosis, or treatment by qualified healthcare professionals.
